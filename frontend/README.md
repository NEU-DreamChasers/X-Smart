Đây là một dự án [Next.js](https://nextjs.org) khởi tạo bằng [`create-next-app`].

## Bắt đầu

Chạy server phát triển:

```bash
npm run dev
# hoặc
yarn dev
# hoặc
pnpm dev
```

Mở `http://localhost:3000` trong trình duyệt để xem giao diện.

Bạn có thể chỉnh sửa file `app/page.tsx` để bắt đầu; trang sẽ tự reload khi thay đổi.

## Tài nguyên

- [Tài liệu Next.js](https://nextjs.org/docs)
- [Học Next.js (tương tác)](https://nextjs.org/learn)

## Triển khai

Có thể deploy lên Vercel hoặc bất kỳ nền tảng host Node.js/Next.js nào. Tham khảo tài liệu Next.js để biết chi tiết.
