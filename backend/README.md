# Backend (NestJS) - Tóm tắt

Đây là phần backend của X-Smart, khởi tạo từ template NestJS. README này cung cấp các lệnh cơ bản để cài đặt, chạy và test ứng dụng backend.

## Cài đặt dự án

```bash
cd backend
npm install
```

## Chạy và biên dịch

```bash
# phát triển
npm run start

# chế độ watch (đang phát triển)


# chế độ production
npm run start:prod
```

## Chạy kiểm thử

```bash
# unit tests
npm run test

# e2e tests
npm run test:e2e

# coverage
npm run test:cov
```

## Triển khai

Tham khảo tài liệu chính thức của NestJS để biết các bước tối ưu khi deploy: https://docs.nestjs.com/deployment
